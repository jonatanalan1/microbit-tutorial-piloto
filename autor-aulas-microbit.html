Acesso ao GitHub sem token salvo

O token fica salvo só neste navegador (não vai pro código, não sai daqui). Se ainda não gerou o token, veja o passo a passo abaixo.

Como gerar o token (fazer só uma vez)
  1. No GitHub, vá em Settings da sua conta > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Em "Repository access", escolha "Only select repositories" e selecione o repositório da aula.
  3. Em "Permissions" > "Repository permissions", ache "Contents" e mude de "No access" para "Read and write".
  4. Defina uma validade (ex: 1 ano) e clique em "Generate token".
  5. Copie o código gerado (começa com github_pat_) e cole no campo acima.
